Same idea as the last lesson, with a different vowel: **o → ue**.

## o → ue: another stem-split

When the stem is stressed, `o` often turns into `ue` for a specific list of verbs.

- dormir → Duermo / Duerme / Duermen
- encontrar → encuentro
- colgar → Cuelgo
- mostrar → muestro / muestra

This is also what was hiding inside `puedo`:

- poder → puedo / puede / pueden / puedes

This is a pattern to recognize, not something you can apply to every random `o` verb. The split happens for particular verbs, not for all of them.

## `me duermo`

This is a one-verb sentence, so the pronoun goes in front:

- Me duermo — I am falling asleep

## More examples you will see constantly

- Duerme / Duermen — he sleeps / they sleep
- Lo encuentro — I find it
- Cuelgo — I hang
