# Lesson 01: `es` / `no es` With Safe Cognates

## What You Will Be Able To Say

- `Es normal.`
- `No es legal.`
- `Es natural.`

## Core Pattern

This lesson gives you your first Spanish sentence factory:

- `Es + adjective`
- `No es + adjective`

`es` means `is`.

At this stage, do not worry about saying `he`, `she`, or `it`. In Spanish, you often do not need the subject pronoun if the context is already clear.

So instead of thinking:
- `It is normal.`

you can start by saying:
- `Es normal.`

## Why This Matters

This lesson gives you a fast, low-friction way to start producing Spanish. You are not learning a full conversation yet. You are learning a reusable frame that lets you recognize and say very basic descriptions right away.

That matters because later lessons will keep reusing the same logic:

- one core frame
- a small vocabulary set
- many possible substitutions

## Build On What You Already Know

This is the first lesson, so there is nothing to stack yet.

For now, the goal is simple:

- control one frame
- control a small word set
- avoid guessing outside the lesson

Later lessons will start combining this frame with new skills. For example, you might later combine a familiar sentence pattern with new verbs, pronouns, or time expressions. But not yet.

## Word-Building Shortcut

Status: `safe`

Many English words that are already close to Spanish can help you very early. For this lesson, use only the approved words below. Do not assume every English word works the same way.

Use only these examples in this lesson:

- `normal -> normal`
- `natural -> natural`
- `real -> real`
- `personal -> personal`
- `legal -> legal`
- `illegal -> ilegal`

Important:
- `illegal` is not `illegal` in Spanish. The standard spelling is `ilegal`.

## New Vocabulary

Core structure words:

- `es` = is
- `no` = not

Adjectives:

- `normal` = normal
- `natural` = natural
- `real` = real
- `personal` = personal
- `legal` = legal
- `ilegal` = illegal

## Watch Out

- Do not add an English subject every time. `Es normal.` is already a complete sentence.
- Do not write `illegal` in Spanish. Use `ilegal`.
- Stay inside the lesson vocabulary. Early confidence comes from controlled accuracy, not from guessing dozens of new words.

## Worked Examples

- `Es normal.` = It is normal.
- `No es normal.` = It is not normal.
- `Es legal.` = It is legal.
- `No es legal.` = It is not legal.
- `Es natural.` = It is natural.
- `No es natural.` = It is not natural.
- `Es real.` = It is real.
- `No es personal.` = It is not personal.
- `Es ilegal.` = It is illegal.

## Sentence Factory

Build many sentences with this frame:

- `Es + adjective`
- `No es + adjective`

Substitute with:

- `normal`
- `natural`
- `real`
- `personal`
- `legal`
- `ilegal`

If you can control one frame with six words, you already have twelve correct sentences.

## Before You Start The Exercise

Make sure you can:

- say what `es` and `no` mean
- recognize all six lesson adjectives
- build both a positive sentence and a negative sentence with each adjective

## If You Get Things Wrong

If the mistake is about structure:
- Go back to the frame and say it slowly: `Es + word` or `No es + word`.

If the mistake is about vocabulary:
- Review only the six approved adjectives for this lesson. Do not add extra guesses.

If the mistake is about spelling:
- Check whether you accidentally kept the English spelling, especially with `ilegal`.

## What The Exercise Should Feel Like

The exercise after this note should feel narrow and repetitive in a good way. That is intentional. At the start, repetition builds control.

The lesson is successful if you can:

- recognize the frame immediately
- choose the right lesson word
- avoid English spelling transfer
- produce short correct Spanish without adding untaught material
